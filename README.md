# Анализ текстов и музыки группы Kunteynir

Итоговая работа по курсу компьютерной лингвистики. Корпус — дискография русскоязычного рэп-коллектива Kunteynir (248 текстов с Genius, 173 аудиотрека из 8 альбомов и EP).

## Цели

1. **Синтаксис.** Измерить структурные характеристики предложений в текстах: длину предложения и позицию грамматического корня (`ROOT`) в нём.
2. **Тональность.** Определить эмоциональную окраску текстов и сопоставить её с ладом музыки (мажор / минор) — есть ли между ними связь.

## Структура репозитория

```
1/   тексты: сбор, очистка, токенизация, кластеризация, тематическое моделирование, тональность
2/   синтаксический разбор (spaCy)
3/   определение лада аудиотреков (librosa)
```

### `1/` — работа с текстами

| Файл | Назначение |
|---|---|
| `saved_artist_lyrics_kunteynir_248_songs.json` | сырая выгрузка с Genius |

### `2/` — синтаксис

`syntax_cloude.py` разбирает `processed_lyrics.txt` моделью `ru_core_news_lg` и считает по корпусу среднюю длину предложения и среднюю позицию `ROOT`.

### `3/` — лад

`attempt.py` определяет тональность каждого mp3 методом Krumhansl–Schmuckler: хромаграмма через `librosa`, корреляция с мажорным и минорным профилями. `info.py` содержит зафиксированный результат — 173 трека с разбивкой по альбомам.

## Методология и ключевые решения

### Очистка данных

Основная сложность работы. Тексты собраны из открытого источника, который редактируют разные пользователи, поэтому одно и то же слово могло быть записано по-разному. В `cleaning.py` убираются:

- скиты и цитаты (строки, начинающиеся с тире или кавычек);
- бэк-вокал в скобках и вставки в звёздочках;
- «висячие» суффиксы вида `'то`;
- нестандартные пробелы (NBSP, MMSP, ZWSP и др.);
- **повторяющиеся строки** — припевы и рефрены, из-за которых модель переоценивала бы связь между словами, реально не связанными даже в пределах одной песни;
- инструменталы, которые Genius не отметил как таковые.

Лемматизация — только `pymystem3`: из проверенных инструментов лишь он корректно сводил разговорные формы (например, «мерс» / «мерса»). Вместо белого списка частей речи используется чёрный: отбрасываются `ADVPRO`, `APRO`, `COM`, `CONJ`, `INTJ`, `NUM`, `PART`, `PR`, `SPRO` — спорные случаи остаются в корпусе. Отдельный список стоп-слов не понадобился.

### Тональность через кластеризацию

Готовые модели анализа тональности на этом корпусе работают плохо: из-за обилия обсценной лексики они размечают как негативные даже песни с вполне позитивным посылом. Поэтому тональность определяется косвенно.

И кластеризация векторов Word2Vec (KMeans), и тематическое моделирование (LDA) давали оптимальное разбиение **на три группы**. Этим трём группам присвоены маркеры «позитивный», «нейтральный», «негативный»:

- в темах: `0` — нейтральный, `1` — позитивный, `2` — негативный;
- в кластерах: `0` — нейтральный, `1` — негативный, `2` — позитивный.

Каждый трек получает пару меток (тема-кластер), которая затем сопоставляется с ладом.

### Сопоставление с музыкой

В `final.py` пары меток сводятся к мажору и минору и раскладываются по категориям:

| Категория | Смысл |
|---|---|
| `match positive` | мажор + позитивные/нейтральные метки |
| `match negative` | минор + негативные/нейтральные метки |
| `strange_major_neg` | мажор при негативных метках |
| `strange_minor_pos` | минор при позитивных метках |
| `strange_major`, `strange_minor` | противоречивые метки (`positive-negative` и наоборот) |

## Результаты

- **Корпус:** 248 текстов → 230 после очистки; 173 аудиотрека; 125 треков, для которых удалось сопоставить текст и аудио.
- **Лад:** в дискографии заметно преобладает минор.
- **Связь текста и лада** прослеживается слабо: значительная доля минорных треков получает позитивные текстовые метки. Точное распределение по шести категориям считает `final.py`; график — `Figure_2.png`.
- `Figure_1.png` — облака слов по темам LDA.
- `lda_visualization.html` — интерактивная карта тем (pyLDAvis).

## Ограничения

- Разметка тональности по кластерам — **интерпретация**, а не результат обученного классификатора; она зависит от того, какому кластеру приписан какой маркер.
- Сопоставление текста и аудио по названиям неполное: часть треков не совпала из-за разночтений в названиях и переизданий альбомов.
